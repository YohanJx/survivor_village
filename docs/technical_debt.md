## 同步修复的相关问题

- 累计建造效果校验实际建筑总等级，不依赖卡牌展示字段；超上限不扣费、不推进时段。
- 条件效果统一读取出牌前建筑状态，建造/条件效果交换排列不会改变条件结果。
- 提交后的信号通知阻止再次执行出牌、阶段推进和读档，避免回调额外消耗时段；查询和界面刷新仍可正常运行。
- 修复原有预览中的 `%g` 格式符；使用 Godot 支持的浮点格式。
- 手牌控件先注入定义再进入场景树，库存刷新和读档复用控件时同步更新文本、锁定与提示。
- 自动存档错误可见，成功提示不会覆盖自动保存失败消息；测试可注入独立手动存档路径。
- 战斗播放为每帧模拟步数设上限，慢帧积压丢弃，不改变每一步的固定时长。
