# 情绪与劳动联动设计提案

日期：2026-10-08。状态：首轮核心已实现，后续扩展仍为提案；数值用于首轮原型试玩，不是最终平衡。透支劳作已按本方案重做。

每日事件、人口出队规模、岗位单位、僵尸、地图资源和照明扩展见 [村庄发展提案](village_progression_proposal.md)。实施人口规模时，本文件中固定单人劳动收益改为所选队伍的基础产出，仍由同一规则入口再应用情绪和策略。

2026-10-10 实现与草案差异见 [当前发展系统](progression_system.md)，实际验证见 [验收记录](validation_report.md)。下表为提案，不把后续医疗债务、地图 Boss 等写成现成功能。

## 参考与设计目标

参考《杀戮尖塔 2》社区 Wiki 的 [Sly / 翻越撑击](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2%3AFlick-Flack)、[必备工具](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2%3ATools_of_the_Trade) 与 [隐藏匕首](https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2%3AHidden_Daggers)。Sly 可以在回合结束前被弃牌时免费打出；必备工具持续提供抽牌与弃牌，隐藏匕首连接弃牌与小刀。这些页面可能混有测试分支内容，因此借鉴触发结构，不照搬版本数值。

由这些例子得出的设计判断：单张牌除了强弱，还应有触发来源、收益接收者和连接不同玩法的角色。同一个行为能让多张牌同时变得有用；一项代价可以被另一张牌利用。上一轮的即时收益/两夜惩罚解决了取舍，但还没有形成这样的组合关系。

本轮建议先围绕一个情绪“烦躁”建立三条路线：轮换工作以保持低费用；集中劳动以换取更高产出；积累情绪后转成守夜能力。首轮不同时加入恐惧、希望、忠诚等多条情绪槽。

## 第一版核心规则

- 烦躁由村庄持有，整数 0–5；先做村庄级情绪，不为每名幸存者建个人情绪。
- 劳动类别与职业分开。首轮类别为林地采集、河畔取水、废墟拆解、建造、技术、训练。不同采集工作不算同一劳动，两个不同建筑图纸仍算同类建造。卡牌显示劳动类别；不依赖显示名称或随意组合的文本标签判断规则。
- 连续第一次同类劳动不增加烦躁；第二次及以后，每次成功执行后烦躁 +1。清晨、午后、黄昏之间连续记录保留。当日人口更多时，每次实际行动也算一次。
- 普通切换劳动会重新开始连续计数，但不直接减少已有烦躁。这样轮换能预防积累，休整仍有作用。非劳动补给事件不伪装成换工，不修改连续记录。
- 每层烦躁使劳动卡体力费用增加 15%，上限 +75%；计算当前牌费用时只读出牌前情绪，新产生的烦躁从下一张劳动牌开始影响。费用先合并，再与职业倍率和情绪倍率相乘，最后统一向上取整；不再对已取整的职业费用二次取整。无体力费用的牌不会凭空产生体力费用。
- 恢复、安抚等非劳动卡不受烦躁加价。“围炉休整”减少 2 层烦躁并重置连续记录；待命保留现有体力 +8，额外减少 1 层烦躁并重置连续记录。待命始终可选，即使补给或体力不足也能逐渐恢复。
- 黎明烦躁 -1、连续记录重置；情绪不每日全部清空。工作产生烦躁和夜间体力恢复惩罚是两种独立规则，不能用同一数值暗中表达。
- 失败执行、预览、悬停、获得奖励和读档都不触发劳动计数。只有已提交的主动出牌触发一次；情绪溢出不算实际获得，降到零后的额外消除也不算实际消除。

例子：没有职业折扣、初始烦躁为 0 时，连续三次林地采集的体力费用为 12、12、14，执行后烦躁分别为 0、1、2。改为采集 → 取水 → 拆解，不会因重复而产生烦躁。烦躁已有 2 层时改去取水仍需支付 30% 加价，想降低费用可以休整或把烦躁转换为其他收益。

## 配套卡牌草案

所有主动卡仍消耗一次行动。下表未列出的原有效果按现有定义保留；新增卡为一次性。比例产出加成仅修正明确标记的正向基础资源产出，向下取整，不增加负面资源变化、返还或条件额外收益。

| 卡牌 | 草案效果 | 在组合中的作用 |
| --- | --- | --- |
| 林地采集 / 河畔取水 / 拆解废墟 | 沿用当前收益和费用，按各自劳动类别触发重复规则 | 常驻基础牌，提供烦躁来源，也可交替使用 |
| 围炉休整 | 保留体力 +32、耐久 +8及补给费用；减少 2 烦躁，清除连续记录 | 通用解法；不要求先抽到稀有解牌 |
| 轮换安排 | 非劳动卡，支付食物 2；今日后续每次切换劳动，当前牌正向基础产出 +20% | 支持低烦躁轮换路线；重复获得不叠加 |
| 劳动号子 | 非劳动卡，支付食物 3；今日每张主动劳动牌实际产生烦躁后，恢复体力 3；每日最多触发两次 | 让玩家有理由接受烦躁；不返还已付费用，也不减烦躁，重复获得不叠加 |
| 熟能生巧 | 非劳动卡，支付材料 4；今日连续第二次及以后的同类劳动，当前牌正向基础产出 +25% | 支持专门劳动路线；烦躁加价继续生效，重复获得不叠加 |
| 宣泄演练 | 训练卡，基础体力 12，要求至少 1 烦躁；消耗至多 3 烦躁，每层令今晚攻击 +8%，重置连续记录 | 把负面情绪转成防守；费用先按原烦躁支付，本牌不再产生重复劳动烦躁 |
| 透支劳作（重做方向） | 保留立即体力 +35及食物/水各 2；把两次黎明恢复 -18替换为烦躁 +2，不改变连续记录 | 主动制造情绪的连接牌；可接宣泄演练，不触发只监听劳动来源的号子 |

“轮换安排”“劳动号子”“熟能生巧”属于仅持续当日的策略效果，黎明失效。先用现有临时修正器机制承载可表达的状态，其余使用原生类型化规则资源；三种策略不是新增情绪。第一轮建议只实现基础烦躁、休整、宣泄演练和重做透支劳作，再加入轮换/专门劳动策略。这样可以先核查情绪有没有形成选择，再扩展触发收益。

## 三条路线的实际抉择

轮换路线：采集 → 取水 → 拆解。缺不同资源时很自然，也能避免新烦躁；轮换安排需要先占用一次行动，其增益主要在高人口或特殊行动需求下回本，早期不应成为必选牌。

集中路线：熟能生巧 → 连续拆解 → 劳动号子配合。这条路线适合紧急追赶建造材料，但更高产出要与加价、噪音和准备行动一起比较。号子最多返还 6 体力，不能抹掉长期加价。不要让“产出加成、费用减免、行动返还”同时无限触发。

转化路线：透支劳作 → 急需的劳动 → 宣泄演练。情绪积累不只是需要清理的垃圾，而是可以选择保留的战斗筹码。演练付费时仍承受已有烦躁，因此不能先清情绪、再用较低费用支付自身。

低人口每天只有三次行动，不能直接照搬尖塔一回合连打多张牌的节奏。基础恢复和转化牌必须单张可用；多张准备牌组合应留给更多人口或后续卡池。首轮不做自动额外出牌和行动返还，所有收益仍有机会成本。

## 展示与实现边界

展示村庄当前烦躁、上次劳动和连续次数；手牌费用直接包含情绪修正。详情确认前显示例如“体力 12 → 14（烦躁 1）”“执行后烦躁 1 → 2”“宣泄：消耗 2 烦躁，今晚攻击 +16%”。让玩家在选择奖励时看出这张牌需要什么来源，已有什么配合；无需显示完整技术事件日志。

实施时由 VillageState 持有情绪、劳动计数和当日策略状态；EffectResolver.cost_totals() 继续作为费用唯一入口，统一计算预览、校验和扣费。CardDefinition 增加有限劳动类别与原生联动定义，不能再造字符串字典卡牌体系。事件限定为主动劳动提交、实际情绪增减等明确枚举，并规定触发顺序；通过规则求值生成完整事务结果后一次提交，不在向 UI 发出的 changed 信号中追加业务结算。

费用、收益条件默认读事务前状态；本牌劳动连续次数、可消耗情绪与待触发收益也在无副作用的规则入口计算。固定顺序为支付校验 → 卡牌主体效果 → 劳动计数及情绪变化 → 有限策略触发 → 一次提交与行动推进。号子看实际劳动产生的烦躁，而非任何正向情绪变化；宣泄的消耗量与加成使用同一份事务结果。达到上限后的溢出不能刷触发，没有实际烦躁时不能白赚宣泄收益。

存档需新增烦躁、劳动类别、连续次数、当日策略状态与已触发次数，并升级版本，旧存档在内存迁移为 0 烦躁、无连续劳动和无当日策略。新局、黎明、奖励恢复和夜间重读各自有明确生命周期。此前旧存档中的运行时恢复惩罚继续按原有剩余夜数结束，未使用的透支牌按重做后的定义执行；不能无意移除已生效的惩罚。

## 首轮验收与平衡观察

实施后检查同类第二次/第三次、换劳动不消除旧烦躁、跨时段/多行动、首次付款与新增情绪先后、上限实际增减、职业与情绪共同取整、补给不足、重复预览、失败无副作用、正常待命解锁、两类策略互斥触发、宣泄条件、存档迁移与到期。UI 实测固定风险、实际费用和奖励联动提示。

试玩重点是：玩家是否主动保留烦躁；是否出现永远先休整的固定套路；集中路线是否只是诱骗玩家超支；轮换准备卡在三行动日是否过弱；基础恢复是否足以避免负反馈锁死。先以 0–5 层、每层 15% 和转化收益为初始值，再依据至少数局不同资源缺口与人口的行为调整。
