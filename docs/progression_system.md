# 情绪、事件与村庄发展：当前实现

日期：2026-10-11。Godot 4.5 首轮可玩实现。本文是当前规则；两份提案保留设计过程和后续方向，数值差异以本文与原生资源为准。

2026-10-10：第一天仅勘探、职业准入与资源跨日存储规则见 [生存逻辑顺序](survival_progression.md)。

## 每日循环与抉择

新游戏默认河谷农村。“新村庄”可选山地聚落、河谷农村、城镇废墟，地图在本局固定。黎明结算上一夜并更新天气、行动额度和烦躁，直接开始白天行动。每日遭遇统一在守夜成功后处理，使用独立种子/日期随机序列，避开最近两种并过滤地图；待处理事件与冷却记录随存档恢复，不重新抽取。

连续第二次及以后的同类劳动，每次成功后烦躁 +1，最高 5；每层让后续劳动体力 +15%。职业、烦躁和事件费用倍率在合并体力费用后一次取整。换工不清除已有烦躁；围炉休整减 2，免费待命恢复 8 体力、减 1，并清除连续记录。黎明减 1。

“透支劳作”立即体力 +35、烦躁 +2，花食物和水各 2；不再新建恢复债务。“宣泄演练”支付当前烦躁下的体力费用，消耗至多 3 层烦躁，每层令今晚攻击 +8%。旧存档已经生效的恢复债务仍按剩余夜数到期。

三种当日策略不叠加，黎明清除：轮换安排让换工的基础正向产出 +20%；熟能生巧让重复劳动基础正向产出 +25%；劳动号子在劳动实际产生烦躁时恢复 3 体力，每日最多两次。烦躁溢出、失败出牌、日终事件和预览不会刷触发。费用、返还与条件额外收益不参与产出放大。

## 日终事件池

每晚守夜成功后随机出现一个遭遇，提供两种处理方式，收益与代价直接结算，不消耗白天行动，也不加入手牌。普通事件必须处理；商队和旅人可跳过，跳过不取得收益也不承担事件代价。完成后照常结算生产与口粮。日终事件使用独立随机序列，避开最近两种事件；读档保持待处理事件。

| 事件 | 处理方式与取舍 | 可跳过 |
| --- | --- | --- |
| 夜间搜集 | 木材 +6、噪音 +6；或零件 +4、污染 +3、下一夜守卫生命 -10% | 否 |
| 围炉分食 | 食物 +8、噪音 +4、污染 +2；或体力 +8、烦躁 +2 | 否 |
| 破损的防线 | 消耗 4 木材修复全部围墙、噪音 +3；或村庄耐久 +10、污染 +3 | 否 |
| 守夜后的争执 | 体力 +12、烦躁 +2；或烦躁 -2、村庄耐久 +5、噪音 +6 | 否 |
| 旅人敲门 | 消耗食物和水各 3，人口 +1、噪音 +4；或消耗药品 1，村庄耐久 +18、噪音 +2 | 是 |
| 路过的商队 | 消耗食物 4、水 2，零件 +8、燃料 +4、噪音 +3；或消耗零件 4，药品 +3、箭矢 +6、噪音 +3 | 是 |

日终食物先供当晚人口消耗，无粮仓的余粮仍清零；新人口立即参与口粮结算，次日统一更新行动额度。噪音随后照常自然减少 3，烦躁在黎明照常缓解 1。新临时效果保留完整下一夜期限，已完成夜晚的黄昏快照不变。第一天白天仍只有勘探，日终不赠送发展卡。

## 地图、资源与队伍

库存保留体力、食物、水、电力、旧材料、噪音、污染，并新增木材、石料、零件、燃料、箭矢、药品。普通建设主要用木材，水井用石料，柴油机、探照灯、工坊、净水器和温室用零件。柴油机每级每天消耗 2 燃料，燃料不足时不产电；不再同时收一份笼统材料维护。电力仍在黄昏只扣一次。

| 地图 | 出队丰度与生成地形 |
| --- | --- |
| 山地聚落 | 木材 ×1.3、石料 ×1.5、水 ×0.75、燃料 ×0.5；高程噪声偏向岩地，林地与遗址按种子分布 |
| 河谷农村 | 食物、水 ×1.25、木材 ×1.2、零件和燃料 ×0.6；湿度噪声生成河流带、草甸与林地 |
| 城镇废墟 | 食物 ×0.75、水 ×0.8、零件 ×1.3、燃料 ×1.5；人工遗址噪声偏向废墟，部分遗址有油料 |

其余丰度为 1。每张地图有不同初始补给；设施日常生产不全局套用出队丰度。“清理沟渠”要求已发现河流与菜圃，地图限定山地/农村，因此无河流的当前山地图不会开放；立即获得 8 水，并使今日农田产出 +25%，无需电力。普通木栅栏可配“石墙工程”获得两夜额外墙体耐久。新常驻行动包括伐木、采石、抽油、制箭、制药、火把照明和远征交易；稀缺资源有可达补充途径。

出队默认每 5 人派 1 人，至少 1、最多 4，不超过人口。村庄信息可选更小队伍，仍只花一个行动。职业决定体力效率，队伍决定规模。以废墟拆解为例，人数 n：体力基础 16 + 6(n−1)，水 2n，零件 8 + 5(n−1)，木材 4 + 2(n−1)，噪音 7 + 3(n−1)。地图/策略再修正正向基础产出，职业/情绪/事件修正体力。工坊的固定额外收益不会被队伍和倍率重复放大。

休整口粮按每 5 人一份增加，演练食物随守卫人数增加，升级建筑每已有一级投入 +25%。免费待命仍可恢复。资源点目前为三类聚合采集余量，各初始 400 派遣份；大队扣更多。余量不足时拒绝并提示缩队；基础采集和取水完全枯竭后，仍可用基础 4 体力取得 2 份补给。当前不是可点击的独立资源点/危险等级系统。

## 职业、装备与夜战

每人有稳定 ID、职业与装备。清晨第一次行动前可免费确认一次分工；当天不追加行动额度。战损按实际死亡身份删除，保留下来的人保留职业，人数汇总始终等于人口。

| 单位 | 当前区别 |
| --- | --- |
| 村民 | 普通投石自卫 |
| 采集者/侦察员 | 移动较快、较脆，发现附近潜伏者，优先酸液与尖啸目标 |
| 建造者/维修者 | 每 5 秒最多耗 1 木材修复附近受损且尚未倒塌的围墙 18 耐久 |
| 工程师 | 每 5 秒最多耗 1 零件修复附近村庄核心 8 耐久 |
| 医护/救护员 | 每 5 秒最多耗 1 药品，治疗附近低于 70% 生命且仍存活的人 22 生命 |
| 守卫/长矛卫 | 较高生命与近战伤害，不主动近距离后退 |
| 守卫/弓手 | 弓具解锁后可装备；射程较远，优先酸液与尖啸目标，逐次消耗箭矢 |

初始五人分别在五种专业；没有弓具时守卫为长矛卫。所有人均参加防守，不额外生成免费人口。职业参数由原生 UnitDefinition 维护。

弓箭零电可使用，箭矢用尽改投石。夜战独立持有黄昏库存预算，每次实际使用记账，战后只扣实际箭、药、木材和零件。读档从相同黄昏预算重演，不重复扣电。探照灯耗 4 电，发现村庄周围潜伏者；现代地图不再增加物理攻击/射程。火把耗木材、不耗电，发现范围较小。兼容地图保留旧灯光加成和旧战斗，防止改变已经保存的黄昏含义。

## 特殊敌人与结束条件

保留蹒跚者、疾行者、蛮力者、Boss；新增披甲者（护甲 4，伤害至少 1，穿甲箭绕过）、酸液感染者（115 范围，须有视线，留下四秒腐蚀区）、尖啸者（每十秒招援，单体最多两次、全夜最多四次）、潜伏者（近距离、侦察员、火把或探照灯范围内可被索敌）、爆燃者（死亡留下四秒火焰，伤害人、附近围墙和核心）。弓手和侦察员对酸液/尖啸目标有优先权。

第 3–4 日新增披甲/潜伏；第 5–7 日酸液/尖啸；第 8 日起爆燃/披甲；山地第 5 日起将第一类替换为潜伏。每夜最多两类新增特殊类型。普通尸、疾行者威胁值 1，蛮力 3、Boss 8，其余特殊类型 2；较强单位替代相应普通威胁额度。情报是候选类型列表，实际随机入场仍由战斗序列决定。召援增加结束预算，不能提前胜利；最后敌人死亡后的残留火焰也必须结算。

村庄毁坏或全部参战幸存者死亡失败。岗位不是另一套独立人口；守卫职业为零仍由其他岗位继续防守。Boss 目前保持通用行为并可有限召援，尚未实现三张地图各自的 Boss、撞击前兆或封路技能。

## 技术与迁移

发展状态由 VillageState 的 VillageProgress 持有，费用与产出通过 EffectResolver 统一，支持纯预览和原子提交。原生 ProgressionRules、DailyEvent、MapDefinition、UnitDefinition、EnemyDefinition 在 `data/` 注册；不增加 Autoload。地图只负责展示，岗位/队伍/事件按钮通过入口调用状态 API。

存档版本为 8，保存待处理日终事件与最近两次日终遭遇；旧战后奖励迁移为当日日终事件。生成地形、路线、目标、制作完成记录及版本 2–6 兼容说明见 [生存逻辑顺序](survival_progression.md)。新版继续保存事件、烦躁、策略次数、分工、队伍、资源余量、名册、黄昏库存及实际耗材战报；恢复在完整验证后提交，旧文件不在读取时改写。

API `new_run(seed, region)` 显式选现代地图；其默认 LEGACY 保留已有调用方与旧规则回归语义。正式主场景显式启动 RURAL，新局窗口传所选地图。

## 首轮边界

已实现上面的经营与夜战闭环；没有将整个长期提案一次扩成完整游戏。医疗求助的两日收容债务、岗位派遣名册细选、个体伤病、独立资源点危险等级、任意建造摆放、地形高度、地图专属 Boss、消防员/陷阱师、机械武器和局外成长仍为后续内容。当前六种日终事件是首轮池，未承诺精确 30%/30%/40% 的事件类别分布。美术为占位绘制，长期多局平衡与其他平台尚未验收。

## 旧存档中的黎明影响

旧版八种黎明事件资源仅保留用于验证和恢复旧存档，不再抽取或显示选择窗口。尚未选择的事件按原计划继续，不扣资源或行动；已经接受的当天费用倍率、烦躁或情报影响保留到次日，不重复发放即时收益。
