## 代码与依赖

- [ ] 显式类型、类型化容器、命名、私有接口、函数顺序及两空行符合规范。
- [ ] 卡牌/建筑用原生 Resource；封闭玩法状态用枚举；稳定配置 ID 仅用于索引、存档和边界。
- [ ] UI 只展示和发起请求；规则不查找场景节点；模拟器不操作 UI。
- [ ] 新增长期静态 UI 布局使用可编辑场景；复杂组件有独立职责，不继续扩大入口脚本。
- [ ] 共享定义只读；运行时状态和嵌套快照有明确复制策略。
- [ ] 没有忽略错误、关闭警告、空异常处理或以动态类型绕过错误。
- [ ] 超过规模审查阈值的函数/脚本有职责拆分或书面理由。

## 规则与状态

- [ ] 固定岗位不追击/退让；噪声仅影响当晚并在黎明归零；污染按地图消退且封顶；威胁与首领准入进入黄昏快照，不按日期线性加怪；忽略普通遭遇不跳过口粮及饥渴后果。

- [ ] 种子生成可重现；选格只允许正交相邻未知区，距离费用显示/校验/扣费一致，线索不提前解锁或显示未知资源。
- [ ] 全部发展卡有共同前置与必要制作依赖，依赖图拒绝未知引用/循环；探索路线和完成记录快照独立复制，存档恢复先验证连续性。
- [ ] 关键词稳定 ID、分类与选择器有效，引用完整注册；人物/地形联合条件在发放、奖励、执行和展示共用，主题不隐含规则。
- [ ] 顶部容量与每日总消耗来自统一入口，含设施与存活人口，查询不改变黄昏快照。
- [ ] 第一天仅勘探；发现、工具、设施、职业前置在解锁、发放和执行共用；打井预览不抽随机。
- [ ] 新局基本发展地形可达，旧档不重筛；当日消耗后按食物、水、电力各自背包与设施容量保留，无容量清零，重复黎明不重结算。

- [ ] 日终不发奖励卡；两项选择都有实际正面和负面效果，普通事件有无补给退路，只有显式普通遭遇可忽略；旧奖励存档迁移、新效果下一夜期限与待处理事件恢复有证据。
- [ ] 费用先汇总验证，失败没有部分扣费、部分建造、时间推进或信号副作用。
- [ ] 前置、等级上限、条件效果与预览使用同一规则，未知效果/配置显式报错。
- [ ] 阶段转换验证来源阶段；重复入夜、战报、事件确认与黎明请求不会重复执行。
- [ ] 加法、乘法、钳制顺序及同优先级联动顺序确定，结果不依赖偶然遍历顺序。
- [ ] 黄昏快照、电力只扣一次、临时效果到期、存活人口消耗和缺粮惩罚有覆盖。
- [ ] 信号在完整提交后发送；回调不会在同一事务中再次执行原操作。
