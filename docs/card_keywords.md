# 卡牌关键词与联合前置

2026-10-10：47 张发展卡与每日事件选项迁移为原生词条引用。旧 `CardDefinition.tags` 文本和 `CardDefinition.discoveries` 地形数组已移除；当局发现集合仍由 `VillageProgress.discoveries` 持有，不改变探索生成或存档枚举。

## 定义与分类

`data/keywords/*.tres` 保存共享只读 `KeywordDefinition`，`data/ui/keywords.tres` 注册 37 个词条；`CardLibrary.keyword_library` 引用同一入口，`CardDefinition.keywords` 使用 `Array[KeywordDefinition]` 引用注册对象。

| 类别 | 内容 | 规则 |
| --- | --- | --- |
| 主题 | 采集、生产、水源、防御等 | 只分类和解释，不暗含前置或效果 |
| 地形 | 河流、林地、石料露头、废墟、耕地等 | 真实探索发现；地形线索不能解锁 |
| 人物 | 采集者、建造者、工程师、医护、守卫 | 检查对应职业人数达到 `minimum_count` |

每个词条有稳定英文 ID、名称、解释与枚举类别。地形类只允许一种选择器：`discovery` 查真实资源发现，或 `biome` 查营地外已探索地貌；人物类指定 `profession` 与最低人数。无效类别、错误枚举、混用选择器、重复 ID、重复卡牌词条、未注册引用均在初始化时拒绝，不发布半有效目录。

`CardDefinition.profession` 保留为执行劳动与体力倍率来源，必须在人物关键词中声明相同职业；其他人物词条表示同时参与或提供专业支持，不另外计算一份体力费用。所有人物与地形词条采用 AND 条件，在村庄整体已探索集合中查询；多个地形条件不要求出现在同一格。例如井位勘探需要「采集者 + 工程师 + 地下水候选地 + 完成挖井工具」。任意一项缺失就不自动发放、不自动发放，已有卡也不能执行，失败不扣费或推进时间。

建筑等级继续使用 `BuildingRequirement`；已完成行动继续使用 `required_cards`，验证未知引用与循环。`SurvivalRules.unlock_error()` 组合共同前置、关键词、制作链与设施；`KeywordRules` 只做无副作用查询，`EffectResolver` 继续统一费用和效果。

## 玩家展示

手牌上方可按「地形 / 人物 / 主题」下的具体关键词筛选已获得卡牌，显示当前数量与手牌总数。筛选不赠卡、不改规则或费用。手牌按实例 UID 复用；详情明确列出地形、人物人数、设施与制作条件。词条悬停仍由 `RichTextLabel` hint 提供；文本正则只负责高亮解释，不执行业务规则。多人物、多地形同时显示在卡牌和详情中。

## 当前地形分支与扩展边界

手牌中的词条继续使用原生悬停说明；右键词条或卡面打开居中的只读卡牌详解，关键词、收益、风险、前置与费用沿用同一查询和格式入口。查看不改变左键选牌、不执行行动，夜战暂停；Esc、关闭按钮或暗色背景收起。

- 河流 + 采集者 → 河畔取水。
- 林地 + 采集者 → 伐木运输。
- 耕地 + 建造者 → 菜圃。
- 废墟 + 采集者 → 拆解，完成后为工程师开放工坊与相关制作链。
- 营地外已探索草甸 → 地下水候选地；建造者准备工具，采集者与工程师勘探井位，再由建造者尝试打井。候选地不保证出水；在地图显式选位并勘探后，每个位置只允许一次付费打井，无水位置永久排除，须换另一个位置。岩地、林地、废墟和营地本身不满足该地形词条。
- 油料点 + 工程师 → 现有遗址油料回收；它表示废弃油料，不是油田。油田专业勘探、石油开采与提炼属于后期内容，本轮没有添加。

新增内容可配置多个地形/人物词条和制作依赖，不为每条产业链增加独立解锁分支。当前地下水候选规则为草甸地貌筛选，尚未模拟水文、单格开采配额或把水井建筑绑定某个坐标。

## 保存与验证

关键词调整本身未新增存档字段（当时版本 7；当前日终事件升级为版本 8）：没有新增运行时字段、重排枚举、移除卡牌 ID 或修改地形种子规则，手牌恢复继续按稳定 ID 取当前定义。版本 2–6 的井具和勘探迁移同时补记相关已完成行动；旧文件不改写。已有井设施保留，已有但不满足新条件的卡锁定，需要发现地形或补足职业后再使用。
