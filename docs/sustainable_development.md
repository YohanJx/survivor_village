# 持续发展路线（2026-10-15）

当前共 69 张发展卡，本轮增加 22 张卡、17 种设施与科技建筑。第一天仍只开放勘探，次日起按真实发现、职业、设施与已完成制作链解锁；不会按日期直接赠送所有设施。完整条件见 [前置清单](card_prerequisites.md)。

## 多条供水与供粮路线

河流 → 河岸引水风车 → 改良引水渠，每天基础水量 10 → 20。井位勘探 → 单次打井 → 成功后风力提水，已有水井 8 加提水 6；无水位置永久排除，不能原地重试。两条路线都可接净水器与灌溉，不要求先建另一条路线。

无河、无井也可建集雨棚与太阳能集水器：晴天合计水 7，雨天再增加 6，另外叠加原生天气产水。集雨棚包含晴日凝露，太阳能集水器需先完成工坊。两者不受河水污染减产。人口扩张和加工用水增加后，需按库存净变化补充供水与储存。

食物可选菜圃、采集营地、河岸渔场；采集营地还可升级林下栽培。灌溉接受任一实际供水路线，并要求水源运行及 3 电力预算；只增益农田，不增益捕鱼、采集。清理沟渠同样只作用于农田。电力可由风力发电或柴油机提供，灌溉建造时也要支付电力费用。

采集营地、轮伐林场、采石场、废料回收站及河岸风车可通过对应科技升到二级，产出、原料和运转噪声按等级增加。缺人或任一原料不足时整批停产，不扣部分原料，不产生该批运行噪声与污染。恢复岗位或补足原料后可继续生产。

河水、井水随污染减产，净水器解除相关损失。生产设施仍有噪声和排放取舍：风力发电与集水不消耗燃料，精炼、回收和采石更加嘈杂；精炼与生物燃料有污染。所有运行状态显示在库存表格下方，可滚动查看，标题与列标题固定。

## 费用与结算边界

`ProductionProfile` 的类型化 outputs / inputs、operator 和天气字段定义生产，`SustainableProductionSynergy` 在 EffectResolver 的统一派生入口查询；共享 Resource 不修改当局状态。优先级先处理供水、供电，然后加工与灌溉，同优先级按稳定建筑 ID 排序，不依赖资源注册顺序。

原料以入夜前库存减已预留消耗检查，不允许提前使用同夜产出的木材等物资。多设施不能重复花同一批原料；口粮和原有设施负担先占用预算。加工用的耐久物资从可供夜战维修/医疗/射击的预算中预留，实际统一在黎明扣除；电力仍仅在黄昏扣一次。冻结快照保存产出和费用，读档后不重算或重复结算。库存显示固定收支，不包含白天出牌费用与夜战临时耗材。

## 防守与内容边界

长矛架提供全营地基础攻击 +2、生命 +12，守望塔提供攻击 +1、生命 +10、射程 +25；长矛与弓箭都可开放守夜训练。敌人基础伤害、压力增益、拆墙能力和入场密度下调，村民基础生命倍率提高，数值与抽样结果见 [夜战平衡](night_threat_balance.md)。仍需合理经营，扩大生产也会提高发展与噪声压力。

本轮沿用营地固定设施占地和自动连接道路。河岸引水通过已发现河流解锁，并以村庄设施的固定产水抽象表现；尚未实现玩家沿河选址、铺设逐格管线或水流运输模拟。69 张发展卡均有独立废土插画；新增设施另有配套的透明地图建筑图。

存档升为 13，建筑数组扩至 33 项，旧枚举索引不变。6–12 版按历史 16 项、2–5 版按历史 13 项校验，再补零迁移；不替旧局建新设施或赠送材料，不改写输入存档。既有具体井位与旧成井迁移继续保留。

实际验证包括三种地图各三组种子的八日路线：不注入库存、建筑或人口，真实探索、出牌、夜战、生产与口粮结算，九局均完成集雨、太阳能、工坊、轮伐与林下栽培，八夜后各保留五人。该测试使用固定策略与测试用路径选择，不证明任意玩家路线、全部种子或无限期经济已平衡。最终检查与证据见 [验收记录](validation_report.md)。
