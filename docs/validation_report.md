## 2026-10-12 · macOS 无终端启动入口

新增根目录 `余烬村庄.app` 薄启动器，Finder 启动无需 Terminal，复用原引擎查找、导入和独立游戏进程；导入及启动错误保存在临时日志，由原生对话框提供打开日志选项。路径以脚本参数传递，不拼接进 AppleScript。需和完整项目一起分发，不是独立 Godot 导出包。README 和开发指南同步。

基础规范 105 脚本零问题，两个 Bash 入口语法检查通过、Info.plist 校验通过、diff 空白检查通过。隔离中文/空格目录的模拟引擎实测：app 静默成功、参数完整转发、入口退出后子进程继续运行；导入失败阻止启动，入口失败码 1，已有错误日志通过参数传给模拟对话框。两个实际 AppleScript 块均 osacompile 编译成功，未执行 Terminal 控制或系统对话框。证据：[入口验证](../test-results/macos_launcher_check.log)、[规范](../test-results/macos_launcher_conventions.log)。
