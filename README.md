# 余烬村庄 · Emberhaven

一款俯视视角的卡牌生存经营与自动塔防游戏。带领幸存者收集物资、发展村庄，在白天为夜晚做好准备，守住尸潮中的最后一片避难所。

你决定村庄如何发展，幸存者在夜间自动作战。每张卡牌都可能带来收益与代价：今天多拿一些物资，可能意味着今晚更响的噪音、更少的饮水，或更疲惫的守卫。

## 游戏特色

- **白天经营，夜晚守村**：安排劳动、建造设施、准备装备，让围墙与陷阱配合幸存者抵御尸潮。
- **卡牌决定发展方向**：40 张发展卡与 8 张每日事件，组合采集、生产、研发和临时战术。
- **三种村庄地图**：河谷农村、山地聚落、城镇废墟，各有不同的资源与发展选择。
- **幸存者分工**：采集者、建造者、工程师、医护和守卫各有所长；安排职业、队伍与装备，兼顾生产和防守。
- **天气与劳动情绪**：晴雨雷雾影响村庄；连续重复劳动会积累烦躁，适时换工或休整能缓解压力。
- **持续生存挑战**：每逢第 7、14、21……夜迎来增强尸潮与 Boss，守夜成功后继续发展。

## 下载与启动

在本仓库点击 **Code → Download ZIP**，将整个压缩包解压后再启动。目前提供项目文件，需要 Godot 4.5 标准版运行。

### Windows

1. 双击项目根目录的 `run_windows.bat`。
2. 如果未找到 Godot，脚本会自动打开官网下载页。下载并解压 [Godot 4.5 标准版](https://godotengine.org/download/archive/4.5-stable/)，将其中的 exe 放到脚本旁边，无需改名。
3. 再次双击 `run_windows.bat`。首次启动需要等待资源准备完成。

如果 Godot 已经放在其他位置，可以直接把它的 exe 拖到 `run_windows.bat` 上。无需下载 .NET 版或导出模板。

### macOS / Linux

用 Godot 4.5 标准版打开解压目录中的 `project.godot`，按 **F5** 启动游戏。

## 一局怎么玩

1. **建立村庄**：选择地图，带领五名初始幸存者开始生活。
2. **选择每日事件**：黎明先处理一张事件，决定当天的机遇与代价；这一步不消耗行动。
3. **安排白天行动**：清晨、午后、黄昏依次进行。选择卡牌，查看右侧的收益、风险和费用，再点击“确认执行”。每 5 人提供 1 次时段行动，最低 1 次、最高 4 次，当天额度在黎明确定。
4. **准备夜间防守**：补足食物与水，建造围墙、陷阱和设施，为守卫准备装备与耗材。黄昏行动用完后自动入夜。
5. **观察自动战斗**：幸存者自行移动与攻击，僵尸会寻找入口、拆墙并攻击避难所。可暂停观察，或切换 1 / 2 / 4 倍速。
6. **选择守夜奖励**：成功守夜后，从三张奖励卡中选一张加入手牌，再迎接次日的生产和补给结算。

采集、取水、休整、拆解与修补等行动可以重复使用；图纸、事件和临时战术通常用后消耗。没有合适的卡牌时，可以选择“待命”，恢复体力并消耗一次行动。

村庄耐久归零或全部幸存者死亡，本局结束。撑过第七夜后仍可继续生存，迎接后续尸潮。

## 生存建议

- 尽早准备木栅栏与弓箭，同时维持食物和饮水供应。弓箭不耗电，但需要守卫装备和箭矢。
- 在每天第一次行动前打开“村庄信息”，安排分工、队伍与守卫装备。专业人员能降低对应卡牌的体力负担。
- 连续做同类劳动会让幸存者烦躁，增加后续体力费用。换工、休整和待命可以缓解压力。
- 招募更多幸存者能增强劳动与防守，也会增加每天的补给消耗。
- 发电机提供电力，也带来噪音和污染；医疗站、灌溉与照明需要各自的物资。建造前先看清设施的收益与负担。
- 高收益卡牌往往会透支未来恢复或今晚战力，确认前留意风险；下划线词条可以悬停查看说明。

## 操作

| 操作 | 作用 |
| --- | --- |
| 点击卡牌 → “确认执行” | 查看并执行行动 |
| Enter | 执行当前选中的卡牌 |
| Space | 暂停或继续夜战 |
| Esc | 关闭说明 |
| 左键或中键拖动地图 | 平移视角 |
| 鼠标滚轮 / 地图下方 −、+ | 缩放地图 |
| 双击地图 / “回到村庄” | 恢复村庄近景 |
| “查看全图” | 查看完整战场 |

## 保存与继续

游戏会在决策与战后自动保存，也可以点击顶部的“保存”。下次启动后点击“继续”恢复进度；夜间存档会从当晚开始重新演绎战斗。
