# 余烬村庄 · Emberhaven

一款俯视视角的卡牌生存经营与自动塔防游戏。带领幸存者收集物资、发展村庄，在白天为夜晚做好准备，守住尸潮中的最后一片避难所。

你决定村庄如何发展，幸存者在夜间自动作战。每张卡牌都可能带来收益与代价：今天多拿一些物资，可能意味着今晚更响的噪音、更少的饮水，或更疲惫的守卫。

界面保留废土与旧金属的风格。顶部集中显示生存状态与全部材料，地图上沿提供视角工具，底部行动导航拥有独立空间。库存窗口固定显示列标题，向下滚动可查看全部资源的每日收支。夜战时显示暂停与倍速按钮。

## 游戏特色

- **白天经营，夜晚守村**：安排劳动、建造设施、准备装备，让围墙与陷阱配合幸存者抵御尸潮。
- **卡牌决定发展方向**：69 张发展卡按地形、人物和主题关键词分类；发现与职业共同决定可用行动。
- **持续发展的多条路线**：河岸风车、井上提水、集雨与太阳能集水都能供水；轮伐、采石、废料回收与工房可自动生产材料、箭矢和药品。
- **遭遇随发展变化**：事件根据探索、设施和村庄状况出现，同一天可连续处理多个遭遇；商队、旅人可跳过。缺粮缺水会在次日清晨引发居民虚弱，连续短缺会加重。
- **逐格探索生成地图**：河谷农村、山地聚落、城镇废墟以不同地形组成网格；先探索，再凭资源发现与方向线索规划发展。
- **幸存者分工**：采集者、建造者、工程师、医护和守卫各有所长；安排职业、队伍与装备，兼顾生产和防守。
- **天气与劳动情绪**：晴雨雷雾影响村庄；连续重复劳动会积累烦躁，适时换工或休整能缓解压力。
- **持续生存挑战**：尸潮随探索、建设、当天噪声与污染变化；高发展与高压力时可能遇到首领，守夜成功后继续发展。

## 下载与启动

在本仓库点击 **Code → Download ZIP**，将整个压缩包解压后再启动。目前提供项目文件，需要 Godot 4.5 标准版运行。

### Windows

1. 双击项目根目录的 `run_windows.bat`。
2. 如果未找到 Godot，脚本会自动打开官网下载页。下载并解压 [Godot 4.5 标准版](https://godotengine.org/download/archive/4.5-stable/)，将其中的 exe 放到脚本旁边，无需改名。
3. 再次双击 `run_windows.bat`。首次启动需要等待资源准备完成。

如果 Godot 已经放在其他位置，可以直接把它的 exe 拖到 `run_windows.bat` 上。无需下载 .NET 版或导出模板。

### macOS

双击项目根目录的 **`余烬村庄.app`**，启动时不会打开终端；请将它与完整项目放在一起。启动失败时显示提示并可打开日志。入口会自动查找 Godot，未找到时打开官网下载页。下载 Godot 4.5 标准版，将解压后的 `Godot.app` 放入“应用程序”或项目根目录，再次双击启动。

`run_macos.command` 仍可用于查看启动过程。成功后尝试关闭独立的启动终端窗口；若系统未允许自动化控制、窗口含其他标签或仍有任务，窗口会保留，关闭错误写入提示的日志。

如果下载的脚本无法双击运行，在终端输入 `chmod +x `（末尾留一个空格），将 `run_macos.command` 拖入终端，按回车后再双击。

### Linux

用 Godot 4.5 标准版打开解压目录中的 `project.godot`，按 **F5** 启动游戏。

## 一局怎么玩

1. **勘探落脚地**：选择地图，带领五名幸存者携带粮水各 35 份开始生活。第一天只能勘探：选择勘探卡，点击与已探索区相邻的亮边未知格，再确认。探索报告提供资源与方向线索，离营地越远越费体力。
2. **查看村庄状况**：留意天气、补给和职业安排，黎明直接开始白天行动。
3. **安排白天行动**：清晨、午后、黄昏依次进行。点击底部圆形类别按钮展开卡牌，通过独立插画辨认卡牌，点击选择，查看下方选中方案的收益、风险和全部资源费用，再点击“确认执行”。每 5 人提供 1 次时段行动，最低 1 次、最高 4 次，当天额度在黎明确定。
4. **准备夜间防守**：补足食物与水，建造围墙、陷阱和设施，为守卫准备装备与耗材。黄昏行动用完后自动入夜。
5. **观察自动战斗**：幸存者固定在营地岗位驻守，迎击靠近防线与进入村庄的僵尸，不主动出村追敌；没有射程内的可见目标时留守岗位。僵尸会寻找入口、拆墙并攻击避难所。可暂停观察，或切换 1 / 2 / 4 倍速。
6. **处理日终事件与报告**：成功守夜后可能出现符合当前情况的遭遇，可选方案或忽略。随后统一结算生产与口粮；饥渴后果不能忽略。结算完成后，“我们活下来了……”报告会显示战果、人口、村庄耐久、探索与各项库存的实际变化，确认后开始新的一天。

采集、取水、休整、拆解与修补等行动可以重复使用；图纸、事件和临时战术通常用后消耗。没有合适的卡牌时，可以选择“待命”，恢复体力并消耗一次行动。

村庄耐久归零或全部幸存者死亡，本局结束。每次守夜成功后仍可继续发展，迎接后续威胁。

## 生存建议

- 地图上方会提示当前发展目标。新局营地两格范围内有草甸与林地，先循线索勘探，再发展水源、储存、生产与防线。山地和城镇废墟没有河流，可选择集雨棚配太阳能集水器，或寻找地下水。
- 留意探索报告中的流水声、树冠和遗址线索，再决定下一步方向；未知区域必须亲自勘探，不能跳格。
- 先发现河流才能河畔取水。探索到地下水候选地（营地外的草甸）后，才开放挖井路线；工具齐备后，采集者与工程师共同勘探井位，再由建造者打井。岩地、林地和废墟不会单凭探索就开放打井。
- 河流发现后可建河岸引水风车，每日基础供水 10；成功建井后可加装风力提水机，水井合计每日基础供水 14。没有河流、也不想冒险打井时，集雨棚晴天凝露 3、太阳能集水器 4，合计 7 份；雨天集雨棚额外增加 6。污染可能影响河水与井水，净水器能保护这两条路线。
- 采集营地、渔场和菜圃负责持续供粮；轮伐林场、采石场和废料回收站负责材料。箭矢工房、药草园、生物燃料作坊与精炼站提供更多长期选择，科技可升级采集与生产。
- 新生产设施需要保留对应职业；缺人或原料不足时整批停产，不消耗原料。工房使用入夜前已有库存，不会提前花掉次日才产出的材料。库存窗口同时显示实际固定收支和停产原因。
- 顶部食物与水显示为 `35(+3)/30`：当前库存、固定生产减消耗的每日净变化、跨日容量；电力显示为 `10/0`。容量为 0 时仍可持有当日补给。
- 随身背包可分别跨日保存 30 份食物与水；粮仓和储水罐各增加 40 份容量。电力需要蓄电池保存；当日消耗后，超出对应容量的余量丢弃。
- 第二天完成勘探后可用 4 份零件建工坊，无需先找到废墟；制作箭矢与弓箭需要先建工坊，制作药品需要先建诊所；详情会列出每张卡的前置。
- 尽早准备木栅栏、长矛或弓箭，同时维持食物和饮水供应。弓箭不耗电，但需要守卫装备和箭矢。围栏形成闭合防线，僵尸须破坏围栏才能穿过，也不能隔着完好围栏攻击村民。
- 在每天第一次行动前打开“村庄信息”的“分工与队伍”页，用 − 释放人员、+ 分配岗位，再确认今日分工；人数始终受现有人口限制。缺少对应职业就不能解锁或执行专业卡牌；职业充足时能降低体力负担。
- 连续做同类劳动会让幸存者烦躁，增加后续体力费用。换工、休整和待命可以缓解压力。
- “敲门的幸存者”每天最多接纳一次，营地最多容纳 12 人；更多人能增强劳动与防守，也会增加每天的补给消耗。
- 发电机提供电力，也带来噪音和污染；建成后还能继续发展探照灯、超载发电与灌溉。医疗站、净水器和守夜训练也是后续发展方向。建造前先看清设施的收益与负担。
- 高收益卡牌往往会透支未来恢复或今晚战力，确认前留意风险；下划线词条可以悬停查看说明。

噪声只影响当晚，黎明清零；设施当天的运转噪声也计入当晚。污染最多 100，河谷每日自然减少 5、山地减少 1、废墟减少 2。第二天起可使用常驻的“熄灯隐蔽”：安静的小营地能避开尸潮，扩大探索与建设后只能减少暴露；同时降低守卫攻击、关闭照明与篝火。火把会破坏隐蔽。

## 操作

| 操作 | 作用 |
| --- | --- |
| 底部圆形类别按钮 | 展开全部、行动、建造、科技或事件卡；再次点击当前类别收起 |
| 展开区上方关键词筛选 | 在当前类别中按地形、人物或主题筛选卡牌 |
| 点击卡牌 → “确认执行” | 查看并执行行动 |
| 新卡获取通知中的卡名 | 查看刚获得的卡牌说明 |
| 右键卡牌（含关键词区域） | 放大卡面，查看完整效果、风险与各项资源费用；“更多说明”展开前置和词条解释；查看期间夜战暂停 |
| Enter | 执行当前选中的卡牌 |
| Space | 暂停或继续夜战 |
| Esc | 先关闭详解或弹窗，再关闭菜单、勘探确认框、目标线索，最后收起卡牌面板；保留卡牌选择，按住不会连续关层 |
| 顶部“库存” / 点击补给数值 | 查看全部材料、固定每日生产、消耗、净变化与容量 |
| 顶部“菜单” | 打开保存、继续、新村庄和帮助 |
| 地图上沿“目标·线索” | 展开当前发展目标和方向线索 |
| 勘探地形 → 点击亮边未知格 → 确认 | 探索相邻区域并查看报告 |
| 勘探井位 → 点击亮边的已探索草甸 → 确认 | 准备此位置的一次打井；无水后须换位置 |
| 左键或中键拖动地图 | 平移视角 |
| 鼠标滚轮 / 地图上方 −、+ | 缩放地图 |
| 双击地图 / “营地” | 恢复村庄近景 |
| “全图” | 查看完整地图 |
| 地图上方“收起卡牌 / 展开卡牌” | 收起浮动卡牌面板以查看地图；再次展开保留当前卡牌选择，收起期间 Enter 不执行卡牌 |

底部独立区域显示五个圆形类别按钮，不与可交互地图重合；每个按钮显示名称、数量与用途：日常行动用于采集和休整，建造设施用于生产和防御，科技升级包含弓箭与灌溉，特殊事件包含招募与补给。开局卡牌区收起，点击类别向上展开；切换类别会清除原选中方案和关键词筛选，避免误执行上一类别的卡牌。空类别会提示暂无卡牌，分类操作不消耗行动或资源。

获得新卡时，界面右上方会显示卡名列表；点击卡名可直接查看说明，列表可滚动，停留鼠标时保留通知。顶部整合时间、天气、资源、地图操作与主要入口，保存、继续、新局和帮助收进菜单；目标和方向线索按需展开。地图作为完整主视图。卡牌面板浮动在类别按钮上方，覆盖部分地图；面板标题、类别高亮和下方指向按钮的连接标记说明它属于哪个类别。类别、数量、关键词筛选、待命和收起共用一条面板工具栏；未选卡时只展示卡牌列表，选中后才显示收益、风险、费用和确认区。勘探卡会收起大面板，改用地图左下方的小确认框；点击 × 或 Esc 关闭后，选地图不会强制弹回，可重新选择勘探卡打开；开合不会缩放地图。卡牌突出收益、风险和全部资源费用，缺少的资源标红，确认按钮紧接费用。前置与结算预览可展开查看。卡牌直接展示大幅末日插画；界面采用与插画一致的灰褐色、旧铁框和磨损底材。第一天仍只开放勘探，新发现对应的行动需从次日起满足职业等前置后获得。

探索后的周围地形会保留在营地视图中；未知区仍有迷雾。营地建筑、幸存者、围墙、枯树和地面采用与卡牌一致的末日绘画风格，界面背景保持低饱和灰褐色。建设设施会增加连接道路，粮仓、储水罐和蓄电池也会出现在地图上。入夜会自动回到营地近景，仍可拖动和缩放。

## 保存与继续

游戏会在决策与战后自动保存，也可以在顶部“菜单”中点击“保存”。下次启动后在菜单中点击“继续”恢复进度；夜间存档会从当晚开始重新演绎战斗。

## 当前版本

井位勘探需要在地图选择一处未尝试的已探索草甸，每个位置只可打井一次。结果为有水或无水；无水的位置永久排除，须勘探另一个位置，重复勘探不会叠加出水概率。旧存档已建水井保留，未成井的旧累计勘探次数需重新选位。水井固定每天产水 8 份，最终净变化还取决于人口、天气与设施。库存表是当日固定收支预估，出牌费用和夜战耗材另行扣除，并非历史流水；日终报告则展示真正结算后的整日变化。

本轮新增 22 张发展卡、17 种设施与科技建筑，并降低早期敌人的伤害与拆墙能力，提高幸存者生命余量。仍需兼顾补给和防线；发展、噪声与污染继续影响威胁。

目前处于原型阶段，69 张发展卡均配有独立废土插画，新增地图设施配有透明建筑图，玩法平衡仍在调整。尚未提供独立安装包，未加入多人、局外成长、多存档槽和完整剧情事件链。Windows 启动脚本已提供，Windows 实机运行仍待验证。
